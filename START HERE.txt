FIRST TIME
1. Ask IT to install Python 3.11 or newer if Python is not already installed. The Windows Store/Python Manager alias is not enough for this automation.
2. From this folder, right-click Setup Once.bat and choose Run as administrator. It creates the local .venv and installs all required packages in one run.
3. Open Classic Outlook with the correct account.

FIRST TEST
1. Double-click Prepare Drafts.bat.
2. Choose Omansh_Test_Dummy_100_Cases.xlsx.
3. Load Outlook accounts and select the test mailbox.
4. Click Test 2 dummy drafts.
5. Check those drafts in Outlook, including banner and multiple assets.

DAILY USE
1. Save today's copied Excel workbook.
2. Double-click Prepare Drafts.bat and choose that Excel file.
3. Load Outlook accounts and select the work mailbox.
4. Click Prepare Outlook drafts.
5. Review and send the messages from Outlook Drafts.

Drafts are saved one at a time without opening message windows.
Nothing is sent automatically. Stop finishes the current case then stops.
If a save is interrupted, check Outlook Drafts first. Then use Reset interrupted cases before retrying.
Rows with the same Case ID combine their assets into one email.
Already processed cases are skipped. Changed or conflicting cases need review.
Keep the Data folder: it prevents repeated drafts across days.
Use one installation per mailbox. Move Data too when moving the installation.
Click Open results folder after a run to see Results.txt.
Without Outlook, Save EML test files lets you inspect individual email files.
Never open or drag all 100 EML files together.
